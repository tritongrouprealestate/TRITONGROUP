TRITON HUMMING VALLEY — how to put this on the server
=====================================================

This zip is the COMPLETE site: page, stylesheet, scripts, fonts, and every
photograph in images/.

  1. In cPanel File Manager, go to the folder the site is served from.
  2. Upload this zip and Extract it there.
  3. That is all. The site has no form, so there is nothing to configure.
     Calls and WhatsApp messages go to +91 90366 82626. (submit.php and
     config.sample.php are left over from the old enquiry form and can be
     deleted.)

WARNING ABOUT IMAGES
--------------------
images/ in this zip holds the working copies of the photographs. If you have
uploaded newer photography to the server yourself, extracting this zip will
OVERWRITE it. If that is a risk, extract everything EXCEPT the images folder,
or back up your images/ first.

Read HANDOVER.md for everything else.
